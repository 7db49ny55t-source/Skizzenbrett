# Skizzenbrett

2D-CAD und CAM in Millimetern: zeichnen, bemaßen, Werkzeugwege planen und G-Code für GRBL, LinuxCNC und Estlcam erzeugen.

## Installieren

**iPad / iPhone:** In Safari https://7db49ny55t-source.github.io/Skizzenbrett/ öffnen → Teilen → „Zum Home-Bildschirm“.

**Windows:** Unter [Releases](../../releases/latest) `Skizzenbrett-Setup.exe` laden und starten. Bei der Windows-Warnung „Weitere Informationen“ → „Trotzdem ausführen“.

**Mac:** Unter [Releases](../../releases/latest) `Skizzenbrett-Mac.zip` laden, entpacken, in „Programme“ ziehen. Beim ersten Öffnen: Systemeinstellungen → Datenschutz & Sicherheit → „Dennoch öffnen“.

## Updates

Beim ersten Start fragt jedes Gerät einmal nach dem Entsperr-Link. Alle Geräte laden beim Start mit Internet automatisch die neueste Version. Ohne Internet läuft die zuletzt geladene weiter. Zeichnungen bleiben auf dem jeweiligen Gerät und werden bei Updates nicht verändert.

## Schutz

Die App liegt hier nur verschlüsselt (`app.enc`, AES-256-GCM). Ohne den persönlichen Entsperr-Link lässt sie sich weder öffnen noch lesen.
